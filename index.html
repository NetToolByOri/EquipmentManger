使用說明

  

    

      
集群分類功能

      

        本工具有兩個「群組集群」，可以讓每一個裝備同時掛上兩種分類。
        例如：群組集群 1 分成「庫房 / 個人」，群組集群 2 分成「正常 / 堪用 / 損壞 / 進場」。
        顯示時可以在排序 A / B 之間切換，用不同角度檢視同一批裝備。
      

    


    

      
分頁功能（Page 1 ～ Page 10）

      

        下方共有 10 個 Page 按鈕，每一頁都是獨立的資料集（各自一份 JSON）。
        例如可以把「工地帽」、「衣櫃」、「電腦配件」分別放在不同 Page，互不影響。
        「多分頁設定」中可以替每一頁改名字，並指定下次開啟時要預先載入哪一頁。
      

    


    

      
缺失統計區＆剪貼簿匯出

      

        缺失統計區會彙整所有尚未結案的缺失，依裝備序號分組顯示。
        「匯出『缺失』到剪貼簿」與「匯出『現況』到剪貼簿」會依照目前顯示欄位，
        輸出成簡單易貼的文字格式，方便貼到 LINE、Discord 或其他通訊軟體回報狀況。
      

    


    

      
JSON 匯出 / 匯入

      

        JSON 匯出會備份當前 Page 的所有資料；匯入則會覆蓋目前這一頁的內容。
        建議定期將 JSON 存到雲端或備份的位置，以免裝置遺失或瀏覽器資料被清除時造成資料流失。
      

    


    

      
瀏覽器環境小提醒

      

        建議使用 Chrome、Safari、Firefox、Edge 等常規瀏覽器開啟本工具。
        若是在 App 內建瀏覽器（例如 LINE 內建瀏覽器）中使用，JSON 檔案下載或匯出有可能受限制，
        建議在檢查提醒後，改用「外部瀏覽器開啟」再使用本工具。
      

    

  


  

  

    
  



    
    

      
平台轉移載入工具

      

        會從 本機內部轉移專用json區 嘗試讀取 Meta 與 10 個 Page JSON 檔，載入到對應 Page 的 localStorage。
